# 在新电脑上安装 / 配置 Anywhere Relay 版

> 本文档对应 `D:\AnywhereRelay\`（带「手机互通」的自编译版）
> 更新日期：2026-10-03

---

## 🧭 总览：新电脑上需要准备三样东西

| # | 需要什么 | 从哪来 | 说明 |
|---|---|---|---|
| 1 | **中继服务器** | ✅ **不用重装** | 它跑在你的云服务器上（1Panel），新电脑只是"连过去" |
| 2 | **电脑端程序** | 下面方式 A 或 B | 带互通的 Anywhere Desktop |
| 3 | **连接配置** | 设置界面填写 | 地址 / Token / 用户ID，**必须和手机一致** |

> 📱 手机端不用重装（除非换手机）——APK 在 GitHub Releases `apk-latest`。

---

## 🅰 方式 A：拷贝现成文件夹（推荐，约 5 分钟）

### 1. 拷贝
把整个文件夹 **`D:\AnywhereRelay`**（约 **479 MB**）拷到新电脑，比如还是放 `D:\AnywhereRelay`。

> 也可以先压缩成 zip（约 200 MB）再拷，拷完解压。
> 用 U 盘 / 局域网 / 网盘都行。

### 2. 运行
双击 **`anywhere-desktop-relay.exe`** 即可。**免安装、免管理员权限。**

> ⚠️ 如果 Windows 弹出 SmartScreen 警告（因为没买数字签名），点「更多信息 → 仍要运行」。

### 3. 配置
进 **设置 → 手机互通**，填（见下方「配置」章节），点保存。

### 4. 注意事项

| 项 | 说明 |
|---|---|
| **设置不跟着文件夹走** | 数据存在 `%APPDATA%\anywhere-desktop-relay`。想要带走设置，见下方「搬运设置」 |
| **`更新.ps1` 路径要改** | 脚本里 `$SRC`（源码目录）指向旧电脑，新电脑若不同步源码，可**直接删掉这个脚本** |
| **路径别含中文/空格** | 放 `D:\AnywhereRelay`、`C:\Apps\AnywhereRelay` 之类都行 |

### 搬运设置（可选）
想在新电脑保留旧电脑的配置/历史，把这几个文件也拷过去：

```
旧电脑:  %APPDATA%\anywhere-desktop-relay\
新电脑:  %APPDATA%\anywhere-desktop-relay\   （同名目录）

需要拷的：
  anywhere-desktop.db.json   ← 设置 / 聊天历史
  relay.json                 ← 中继连接配置（如果存在）
```

> 🚫 **千万别用「记事本」编辑 `relay.json`！** 记事本保存会加 UTF-8 BOM，程序会解析失败。
> 用 VS Code / Notepad++（存为「UTF-8 无 BOM」），或者干脆用**设置界面**保存。

## 🅱 方式 B：在新电脑从源码构建

适合你想在新电脑也维护源码、以后自己更新。

### 前置环境

| 工具 | 版本 | 说明 |
|---|---|---|
| **Node.js** | ≥ 20（推荐 22 LTS） | https://nodejs.org |
| **pnpm** | 10.x | `npm i -g pnpm` 或 `corepack enable` |
| **git** | 任意较新版 | https://git-scm.com |
| **代理** | 视网络 | 国内拉 GitHub / Electron 需要（见下）|

### 步骤

```bash
# 1) 拿我们的补丁 & 脚本
git clone https://github.com/Obscurro110/anywhere-mobile.git
#    → desktop-integration/ 里有 anywhere-desktop-relay.patch 和 更新.ps1

# 2) 拿官方源码
git clone https://github.com/Komorebi-yaodong/anywheredesktop.git anywhere-desktop-src
cd anywhere-desktop-src

# 3) 建分支并应用补丁
git checkout -b anywhere-relay
git apply /path/to/anywhere-mobile/desktop-integration/anywhere-desktop-relay.patch
#   ↑ 若整包失败，按文件逐个打：
#     git apply --include=main/index.js       <补丁>
#     git apply --include=package.json        <补丁>
#     git apply --include=preload/main_preload.js         <补丁>
#     git apply --include=render/main/components/Setting.vue <补丁>
#     git apply --include=electron-builder.yml <补丁>
git add -A && git commit -m "feat: relay integration"

# 4) 装依赖 + 构建
pnpm install
pnpm run build

# 5) 打包（关键：复用本地 Electron，避免下载失败）
npx electron-builder --dir --publish never "-c.electronDist=node_modules/electron/dist"

# 产物：dist\win-unpacked\anywhere-desktop-relay.exe
```

### 国内网络提示

- `pnpm install` 要下 Electron（~130 MB）。项目 `electron-builder.yml` 已配了国内镜像：
  `electronDownload.mirror: https://npmmirror.com/mirrors/electron/`
- 如果 `electron-builder` 仍报下载失败（`access ... forbidden`），**务必加** `-c.electronDist=node_modules/electron/dist`
- 拉 GitHub 不通就用代理（`更新.ps1` 里 `$PROXY` 可配）

## ⚙️ 配置（两种方式，二选一）

### 方式 1：设置界面（推荐 ✅）

打开应用 → **设置 → 手机互通**，填：

| 字段 | 值 | 说明 |
|---|---|---|
| 中继服务器地址 | `wss://你的域名/ws` | 你部署的中继地址 |
| Token | 你的中继令牌 | **和手机端完全一致** |
| 用户ID | 例如 `default-user` | **和手机端完全一致** |
| 设备名称 | 例如 `My PC` | 手机上显示的这台电脑名字 |

点 **保存** → 会自动重连，上方状态应变 **🟢 在线**。

### 方式 2：配置文件

在 `%APPDATA%\anywhere-desktop-relay\` 里放 `relay.json`：

```json
{
  "serverUrl": "wss://你的域名/ws",
  "token": "你的中继令牌",
  "userId": "default-user",
  "deviceName": "My PC"
}
```

> ⚠️ **UTF-8 无 BOM**！用记事本会加 BOM → 程序解析失败。
> 或者启动应用让它自己在设置界面生成。

### 也支持环境变量

`ANYWHERE_RELAY_URL` / `ANYWHERE_RELAY_TOKEN` / `ANYWHERE_RELAY_USER_ID` / `ANYWHERE_RELAY_DEVICE_NAME`

## 📱 手机端

1. 下载 APK：GitHub Releases → `apk-latest` → `anywhere-mobile.apk`
2. 安装（需允许「安装未知来源应用」）
3. App 里填**相同**的：服务器地址 / Token / 用户ID
4. 「设备」页应能看到你电脑的**设备名称**

---

## ✅ 安装后检查清单

- [ ] 应用能打开
- [ ] 设置 → 手机互通：填好并保存，状态 **🟢 在线**，显示本机 ID（`desktop-xxxx`）
- [ ] 手机 App 能连上（同样显示在线）
- [ ] 手机的「设备」页能看到电脑名称
- [ ] 手机发条消息 → 电脑收到；电脑能发回手机

> 若「离线」：① 地址是不是 `wss://…/ws`（别漏 `/ws`）② Token ③ 两端 `userId` 是否一致

## 🧱 常见问题

| 现象 | 处理 |
|---|---|
| 双击没反应 / 闪退 | 试试右键「以管理员身份运行」；或检查杀软拦截 |
| 提示缺 `VCRUNTIME140.dll` | 装 [VC++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| 状态一直「离线」 | 检查地址/Token/用户ID；确认服务器在跑（浏览器开 `https://你的域名/health` 应返回 `{"ok":true,...}`）|
| 保存报 `No handler registered` | 你用的是旧版 → 换成本目录这个新版 |
| 手机看不到电脑 | 两端 `userId` 必须一致 |
| 和官方版冲突不能同开 | 本版叫 `anywhere-desktop-relay`，理论上可并存；若不行说明用的是旧版 |
| 用记事本改了 relay.json | 删掉重新在设置界面保存（BOM 会搞崩）|

---

## 📌 三条铁律

1. **别用记事本编辑 `relay.json`**（BOM 会搞崩）→ 用设置界面
2. **新版和官方版可以共存**（不同 userData），但要记住各自的数据目录：
   - 官方版：`%APPDATA%\anywhere-desktop`
   - relay 版：`%APPDATA%\anywhere-desktop-relay`
3. **更新用 `更新.ps1`**（或在源码目录 `git rebase origin/main` 后重新构建）
